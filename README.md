# Book Management REST API

## Project Overview
This project demonstrates CRUD operations using Node.js and Express with in-memory storage.

## Features
- Get all books
- Get a single book by ID
- Add a new book
- Update a book
- Delete a book

## Technologies
- Node.js
- Express.js
- Postman

## Installation
```bash
npm install
npm start
```

Server URL: http://localhost:3000

## API Endpoints
| Method | Endpoint |
|---------|----------|
| GET | /books |
| GET | /books/:id |
| POST | /books |
| PUT | /books/:id |
| DELETE | /books/:id |
